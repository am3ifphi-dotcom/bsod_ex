# BSOD_EX // 0x000000F4

一人称視点で体験する短編ホラー／グリッチ・インタラクティブ作品（Three.js + TypeScript + Vite）。

## 体験の流れ

1. **夜の自室（02:47 AM）**  
   生活感のある深夜の自室を `WASD` + マウス視点で自由に歩けます。机の上のゲーミングPCのモニターだけが青く光り、静かな不穏さを漂わせています。
2. **本物のBSODと「`:(`」の狂気・捕食遷移**  
   PCに近づいて調べ、BSOD左上の大きな `:( ` にカーソルを重ねて3回だけ触れると、静止していた表示が「認識 → 汚染 → 侵入」の順で崩れます。文字を大量に足すのではなく、画面そのものが信号欠落・分裂・空間的な裂け目へ変質します。部屋の壁・床・天井までもがモニターの青に侵食されて物理的に引き剥がされ、頭部の抵抗感・ためらいを伴う一人称カメラ演出でモニター内部へ吸い込まれます。
3. **BSODグリッチ世界**  
   歩ける立体地形、巨大サーバー群、空に重なる巨大なウィンドウ枠と逆さの都市、浮遊するCRTモニターや破損UI、マザーボードの断層、静寂と異常波の緩急を備えた3D異世界を探索できます。パケット断層、欠けた座標ハロー、逆さの都市などの巨大な構造物群は探索・観察のための任意の景観です。脱出コマンド **`WAKE_UP`** は異世界に到着した時点で手元のコンソールから実行できます。
4. **ゲーム内コンソール（`C`キー）と世界の崩壊・落下**  
   異世界では場所を問わず `C`キーでローカル回復コンソールを起動できます。`WAKE_UP` を実行するとその場から崩壊イベントが発生。左右を見回し、足元の亀裂を追い、後ずさりして足場を失い、砕け散る床の破片とともに深淵へ落下する完全一人称の強制カメラ演出が展開されます。
5. **自室への帰還と余韻**  
   落下の勢いのまま深夜の自室のラグへ叩きつけられるように帰還。回転した椅子や机の上に残された青い結晶片、モニターの残留ログなど小さな異変が余韻を残し、そのまま再び探索・再プレイ（`R`キーまたはメニュー）が可能です。

## 操作方法

- `W A S D` / 矢印キー : 移動
- `マウス` : 視点移動 / モニター調査時のカーソル操作
- `左クリック` / `E` : PCモニターを調べる・カーソルを合わせた「`:(`」に触れる
- `右クリック` / `Q` : モニターから離れる（侵食初期のみ）
- ポインターロックが使えない場合は、ドラッグで視点を動かせます。
- 画面の点滅や急な音・カメラ演出があります。
- `C` : 緊急コンソールを開く（異世界内・どこでも）
- `ESC` : 一時停止・感度／音量設定・やり直しメニュー
