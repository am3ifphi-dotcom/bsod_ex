# BSOD_EX // 0x000000F4

一人称視点で体験する短編ホラー／グリッチ・インタラクティブ作品（Three.js + TypeScript + Vite）。

> **"THE SCREEN DOES NOT BREAK"**
> 画面は壊れません。壊れるのは、こちらが信じていた「動かないはず」という前提です。

---

## 体験の流れ

1. **夜の自室（02:47 AM）**
   生活感のある深夜の自室を `WASD` + マウス視点で歩けます。机の上のゲーミングPCのモニターだけが青く光っています。

2. **止まったままの BSOD と、一文字ずつの不同意**
   PCに近づいて調べると、そこにあるのは**本物の停止画面そのもの**です。牙も、喉も、眼球も、説明ダイアログも出てきません。クリックしても何も起きず、ほんの一瞬だけ「効いた」と錯覚して、すぐ上書きされます。

   代わりに、画面は**一箇所ずつ**静かに書き換わります。

   | 段 | 変わるもの |
   | --- | --- |
   | 0 | 本物の停止画面 |
   | 1 | **何も変わらない**（間） |
   | 2 | 一語：「PC を再起動する」→「**あなた**を再起動する」 |
   | 3 | 一文字：`:(` → `:)`（同じフォント、同じ座標） |
   | 4 | 停止コードが変わり、ガラスに部屋の反射が浮かぶ |
   | 5 | パネルが**消える**。走査線の残影だけ |

   進行はクリックではなく**カーソルを動かしているかどうか**で決まります。手を止めて見つめている間、機械は完全に止まります。少しでも動かした瞬間に書き込みが進み、動かさないままでも、やがて勝手に進みます。部屋は剥がれ落ちたりせず、**最初から一枚の表示面だった**ことが、走査線だけから判明します。

3. **無限ページ・コンジットと異世界への着地**
   暗転したパネルの奥は、同じ停止画面のページが無限に後退していくデータ導管です。肉の喉ではなく、ずれた頁、走査線、光のトレース。そのまま 3D 異世界の空へ継ぎ目なしに抜けます。

4. **「存在が途中で打ち切られた」世界**
   高さ 160m の大聖堂は、ある高さで**描画がキャンセルされた**まま立っています。下は黒曜石の実体、上は細いワイヤ、さらに点、そして何もない。平らな切断面からは光ファイバーが垂れ下がっています。

   その周囲に：
   - **欠落フィールド** — 毎フレーム 12%（異常波時は最大 40%）の構造が消え、輪郭だけが残る
   - **ページ層** — 右端 20% が千切れた巨大な停止画面の頁が 116 枚、わずかにずれて重なる
   - **データ血管** — 空を走る光の導管が途中で終わり、粒子の滝になる
   - **グリフの嵐** — `:(` `0x` `99%` `WAKE` `02:47` の断片が 700 個、空間に漂う。8個に1個が時々書き換わる

   かつて立っていた「説明看板」は撤去しました。情報は掲示されず、空から降ってきます。

5. **コンソールはどこでも、最初から**
   `C` でカーネル回復コンソールを開くと、**ブートバナーの 3 行目に `WAKE_UP` が最初から印刷されています**。塔へ行く必要はありません。距離チェックも、信号不完全の拒否も、コマンド発見のフェッチクエストもありません。

   塔（演算核）は任意の寄り道になりました。行けば `WRITE_COUNT : 6` の記録と追加のアーカイブが読めるだけです。緊張は「何を打つか」から「**もう知っているそれを、打つのか**」へ移ります。

   `WAKE_UP` を実行すると崩壊イベントが発生。足元の亀裂、砕け散る床、深淵への完全一人称落下を経て、深夜の自室のラグへ叩き戻されます。

6. **帰還と余韻**
   暗いままのモニター、わずかに回転した椅子、時々一桁落ちる時計。`R` で最初から、`ESC` でメニュー。

## 何が変わったか（全面刷新の要約）

| | 旧 | 新 |
| --- | --- | --- |
| BSOD 演出 | `:( ` を 6 回クリック → 牙・顎・眼球・喉・LiDAR の怪物・委譲ダイアログ | クリックは**無効**。本物の停止画面が一文字ずつ書き換わるだけ |
| 入力 | クリック連打で段階解放 | **静止**。動かさないと止まり、動かすと進み、動かさなくても進む |
| 部屋 | 壁・床・天井が青に侵食され物理的に剥がれ渦に吸われる | 剥がれない。部屋が**最初から表示面だった**と走査線で判明する |
| 吸い込み | wet な食道 → 歯 → 奥の瞳 | 無限に後退する**停止画面のページ層**（異世界の導管と同一パレット） |
| 字幕・説明 | 脊髄のアンマウント、振り返るな、など逐一説明 | ほぼ撤廃。短い断片のみ |
| 3D 造形 | 塔・アーチ・滝・リヴァイアサン | 上記に加え**描画が途中で終わった建造物**と欠落フィールドを主役に |
| 案内 | 日本語の長文が書かれた四角い掲示板 ×2 | 撤去 → 空中のグリフ断片に分散 |
| コンソール | 塔に近づかないと `WAKE_UP` が `ACCESS DENIED` | **最初から・どこからでも**実行可。塔は任意の記録 |

「画質を上げる」のではなく、**足すことをやめる**方向に振り切りました。牙やダイアログは「画像そのものが効いていない」という告白だったからです。

## 操作方法

- `W A S D` / 矢印キー : 移動
- `マウス` : 視点移動 / モニター調査時のカーソル（＝視線）
- `左クリック` / `E` : 調べる（調査中は押しても反応しません）
- `右クリック` / `Q` / `ESC` : モニターから離れる（いつでも可能。離れても書き込みは巻き戻りません）
- `C` : カーネル回復コンソール（異世界ならどこでも）
- `R` : 帰還後、最初からやり直す
- `ESC` : 一時停止・感度／音量／描画プリセット
- ポインターロックが使えない場合はドラッグで視点移動できます。
- 音声・急なカメラ演出があります。ヘッドホン推奨。

### コンソールの主なコマンド

`WAKE_UP`（終了）、`STATUS`、`LOOK`、`SIGNAL`、`DUMP`、`PS`、`DIR`、`WHOAMI`、`HELP`、`CLEAR`。
`REBOOT` など標準の電源割り込みは拒否されます。

## 設計原則

1. **足さない。** 停止画面は「止まっている」ことで怖い。グリッチの予算は 3D 世界にだけ使う。
2. **説明しない。** 赤い目、LiDAR の読値、クリティカルな警告文は全部削った。気づいた人だけが気づく差分を置く。
3. **奪わない。** 移動を強制しない、離れられなくしない、クリックを強要しない。その代わり、プレイヤーが決めていないことは確実に進む。

## 開発・ビルド

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
npm run verify     # シェーダ検証 + 型チェック + ビルド + 全テスト
npm test           # 6 種類の回帰テスト
```

### テスト内容

| コマンド | 検証すること |
| --- | --- |
| `test:canvas` | 実 canvas で 6 ステージをピクセル比較し、「段 0 と 1 が完全一致」「各段の差分が極小」「段 5 が暗転」「解剖メッシュが不在」を証明 |
| `test:bedroom` | 部屋が剥がれないこと、全タイムラインで例外が出ないこと |
| `test:world` | 全ビルダー、欠落構造の存在、看板が無いこと、行列の有限性 |
| `test:console` | 塔ゲートが無いこと、バナーに命令が出ること、reset 安全性 |
| `test:arrival` | 到着カメラが 120Hz サンプルで構造に衝突しないこと |
| `test:handoff` | ページ導管 → 3D 世界のカメラ連続性 |
