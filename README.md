# BSOD_EX — :(

一人称視点で遊べる短編ホラー／グリッチ体験（想定プレイ時間 15〜25分）。
夜の自室でPCのブルースクリーン（BSOD）を調べ、連打の果てに画面へ「食われ」、
BSODの青とエラー文字でできた異世界を探索し、世界の秘密を見つけて帰還する——
全工程を1本のカメラでつないだ、完成したインタラクティブ作品です。

---

## 起動手順（すぐ遊べます）

前提: Node.js 18+（開発・検証は Node 22 / Chrome）

```bash
npm install
npm run dev        # → http://localhost:5173 をブラウザで開く
```

本番ビルドの場合:

```bash
npm run build      # → dist/ に出力
npm run preview    # → http://localhost:4173
```

`dist/` フォルダは静的ホスティング（GitHub Pages等）にそのまま置けます（相対パス配信）。

### 任意: 高品質テクスチャで差し替える（Poly Haven / CC0）

同梱素材だけでも完全に動作しますが、以下で Poly Haven(CC0) の木床等に自動で差し替わります。

```bash
npm run fetch:polyhaven   # Poly Haven公式APIから1k PBRを取得（要ネット接続）
```

同梱の外部素材（three.js / ambientCG のPBRテクスチャ、Khronos公式 Lantern モデル）の
再取得・再変換は `npm run fetch:github`（要 Python3 + Pillow）で行えます。
ライセンス内訳とクレジットは [CREDITS.md](./CREDITS.md) とゲーム内 Esc メニューを参照。

## 操作方法

| 操作 | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| マウス | 視点（ポインタロック不可の環境ではドラッグ視点に自動切替） |
| Shift | ダッシュ（歩行の2倍） |
| E または クリック | 調べる |
| F | 手持ちライト ON/OFF |
| Esc | メニュー（感度・音量・グリッチ強度・カメラ揺れ・画質・クレジット） |
| F3 | パフォーマンス表示 ON/OFF |
| その他 | 物語の中で見つけてください |

マウス感度は Esc メニューのスライダーを動かした瞬間に反映されます（0.2〜3.0）。
設定は localStorage に保存されます。

## 技術選定と理由

- **Web（Vite + three.js / WebGL2）** を選択。理由:
  - インストール不要で「手元で再現してすぐ遊べる」形にでき、配布・起動の再現性が最も高い。
  - three.js の PBR（MeshStandardMaterial）＋ ACES フィルミック・トーンマッピング＋ HDR ポスト
    （UnrealBloom + 自作フィルム/グリッチ/吸い込みシェーダ）で質感を確保しつつ、
    描画コール 60〜160・三角形 9万未満（F3実測、後述）に抑え 60fps を狙える規模に設計。
- 衝突判定は物理エンジンを使わず **解析的コリジョン**（歩行面レクト/ランプ + AABB壁）。
  「移動先に地面がなければその軸の移動を棄却」する構造で、ダッシュ時の
  マップ外落下・壁抜けを原理的に防いでいます（サブステップ分割でトンネリング防止）。
- 音は外部ファイルなしの **Web Audio 全合成**（空間音響 PannerNode、生成インパルスの残響、
  マスターにコンプレッサーでラウドネス管理）。素材ライセンス事故が起きません。

### 映像まわり

- PBR、ACES、リニア/HDRレンダリング、PMREM環境反射、ブルーム、フィルムグレイン、色収差
- 被写界深度は自作シェーダのラジアルブラー（PC調査時のみ強く）
- グリッチはポスト（スライス/RGBずれ）に加え、**ジオメトリ変形**（モニタ画面の膨らみ、
  浮遊破片の伸縮・崩壊する地面の実落下）、**テクスチャ**（ブロックノイズのデータクロール）、
  **ライティング**（モニタ光の明滅・看板の点滅）にも異常を起こします
- 霧は FogExp2（エリア別に密度が変化）。遠景は画像ではなく実3Dのモノリス群+浮遊島
- 動的解像度（フレーム時間EMAで 0.58〜1.0 倍を自動調整）+ 画質プリセット4段

## 体験の流れ（ネタバレなし + 制作メモ）

1. **自室** — モニタ光を主光源（スポットライト+影）に、時計の秒針（実際に進み音も定位する）、
   PCファン（回転+定位音）、遠い車の音など。PCに近づくとプロンプトが出ます。
2. **BSOD調査** — 視点が頭の傾けと共にモニタへ寄り被写界深度が変化。
   「:(」をクリックするたび 12 段階で異常が進行（文字化け→スライス→画面の膨らみ→
   部屋の光の明滅→吸い込みワープ→顔の巨大化→口が開く）。
3. **捕食遷移** — カメラは顔の口を通ってエラー文字のトンネルを抜け、異世界の到着地点へ。
   フェードなしの1本カメラ（トンネル内部の暗部でシーンを不可視に切替）。
4. **異世界（複合大マップ）** — 全長約400m、5エリアをシームレス接続:
   ①到着エリア（青い荒野・西方の遺跡） ②崩壊した大建築（吹き抜け・階段2基・上階回廊・秘密の部屋）
   ③侵食された都市（街路・入れる店舗・路地の足場登り・CC0ランタン） ④深層（暗い回廊・サーバールーム・小部屋）
   ⑤中心構造物（尖塔・回転するリング・天へ伸びる光柱）。空には巨大な「:(」が常に見えるランドマーク。
   任意収集の「断片」×7（世界の断片的な記録と、脱出への示唆）。
5. **コンソールと崩壊** — 世界内の破損UIから在り処が示唆されます。コマンドは help/status/scan/cat 等の
   疑似コマンド+未知コマンドへの不穏な応答を用意。世界の秘密の言葉だけが崩壊を起こします
   （未発見のまま打っても「参照が壊れている」と弾かれます）。崩壊は強制一人称カメラ演出
   （目→頭の二段遅れの視線移動、ひび割れの追跡、たじろぐ足取り、息づかい）、
   地面の破片は実際に傾き・落下し、プレイヤーも奈落のシャフトへ落ちます。
6. **帰還** — 落下の勢いのまま自室の床へ。部屋には小さな異変が残ります
   （止まった時計、倒れた椅子、机の上の何か、モニタの待機画面…）。
   PCを再び調べると状態が完全に初期化され、最初から遊び直せます。

## 安全配慮

- 開始時に注意表示。画面全体の強い点滅は入れていません（明滅は小面積・低頻度に制限）。
- Esc メニューで「グリッチ演出の強度」「カメラ揺れ／ヘッドボブ」を下げられます
  （強制演出の震えにも反映）。

## 性能と計測について（正直な注記）

開発サンドボックスには GPU がなく、検証は Chromium + SwiftShader（ソフトウェア描画）で行いました。
そのため **実GPUでの avg fps / 1% low の実測値は未取得** です（ソフトウェア描画の数値は無意味なため記載しません）。
代わりに、計測手段と負荷の実測内訳を用意しています:

- **F3 パフォーマンス表示**（avg fps / 1% low / フレームms / 描画コール / 三角形 / 解像度倍率）を常備。
- **描画負荷の実測（F3、headless確認）**: 異世界 60〜152 calls / 17k〜89k tris、自室 23k tris。
  ミドルクラスGPU（RTX 3050 / GTX 1660 / M1）であれば 1080p・60fps を十分狙える規模です。
- **`?autotest=1`** を付けると全エリアを自動で巡回し、42秒間の avg / 1% low を画面と
  コンソールに出力します。お手元の実機でご計測ください:
  `http://localhost:5173/?autotest=1`
- 負荷対策: 静的ジオメトリのマテリアル別マージ、破片のインスタンシング、エリアライトの距離カリング、
  影の解像度/距離制限（ライトは手持ち・モニタ・太陽のみ影オン。画質「低」で影オフ）、動的解像度。

## 検証済み項目（Chromium ヘッドレスで全自動プレイ + 目視確認）

- タイトル → 自室を歩く → プロンプト → Eで調査 → 「:(」を実クリック×12（段階進行）→
  捕食トンネル → 異世界到着 → 歩行 → コンソール（help / 未知コマンド / 未発見時の正解ワード / status）→
  尖塔で発見 → 正解ワード → 崩壊演出 → 落下 → 自室へ着地、まで通しで到達（JSエラー0件）。
- 5エリア全てにテレポートし描画目視（建築の上階回廊の歩行面、店舗内装、深層+ライト、広場と尖塔）。
- 断片の取得、Escメニューと感度スライダーの即時反映、クレジット表示。
- コンソールの空Enter・空白・大文字小文字・別形ワード・Esc/Cでの開閉、コンソール再オープン。
- 帰還後にPCを調べ直すと clicks/断片/発見フラグ等が完全初期化されること。
- 外部アセット（テクスチャ11点 / Lanternモデル）の取得成功とゲーム内ロードを確認
  （コンソールに `[BSOD_EX] external textures: ... lantern: true` と出ます）。

### 未検証・既知の制限

- 実GPUでの fps 実測は未実施（上記 autotest で計測可能）。SwiftShader 上では約1〜2fpsのため、
  演出のタイミング自体は実時間ベースで確認していますが、滑らかさの最終確認は実機でお願いします。
- 音の最終バランス（定位・音量）はヘッドレスでは聴感確認ができていません（合成パラメータでの設計のみ）。
- ポインタロックが使えない環境（iframe の権限ポリシー等）ではドラッグ視点に自動切替します。
  その場合 Esc メニューは Esc キーで開閉します。
- SSAO/GTAO の代わりに、テクスチャのAO的陰影・霧・ブルームで立体感を出しています（軽量化のため）。
- モバイル/タッチ操作には対応していません（PC・キーボード+マウス前提）。

## デバッグ手段（通常プレイでは無効）

URL に `?dev=1` を付けると有効化されます:

- `1` 自室へリセット / `2` PC調査 / `3` 異世界到着地点 / `4` 中心構造物 / `5` 崩壊開始
- ゲーム内コンソールで `debug goto spire`、`debug givekey`、`debug pos`
- `?autotest=1` で性能計測ツアー
