# BSOD_EX — 一人称ホラー / グリッチ体験

夜の自室 → PC の BSOD → 異世界(グリッチ大マップ)→ 崩壊・落下 → 帰還、までを 1 本のカメラで繋ぐ短編インタラクティブ作品です(初見通し 15〜25 分目安)。

---

## 0. 選定理由(実装環境)

| 項目 | 選定 | 理由 |
|---|---|---|
| 実行形態 | **Web (WebGL2 / Three.js + Vite + TypeScript)** | インストール不要で「npm 2 コマンド → ブラウザで遊ぶ」を最短にできる。WebGL2 は RTX 3050 / GTX 1660 / M1 クラスで 1080p60 の余裕があり、PBR・HDR・ポストプロセス・インスタンシング・カスタムシェーダが揃う |
| レンダラ | Three.js r171 (WebGL2) | glTF 2.0 / HDR 環境 / 影 / ACES トーンマッピング / カスタム GLSL を一式サポート |
| ポストプロセス | three 標準 EffectComposer(自作グリッチ/表示パス含む) | SSAO・Bloom・被写界深度・グレイン・ビネット・走査線を 1 チェーンで制御でき、品質プリセットでコスト管理しやすい |
| 音 | **Web Audio API で全音を合成(自作)** | 「CC0 または自作(合成)」の要件を満たす最も確実な方法。空間音響(Panner)・生成リバーブ・コンプレッサーでラウドネス管理 |
| アセット | GitHub の高品質公開アセット(下記)を取得スクリプトで再現 | ライセンス確認済みのものだけを採用。巨大ファイルはリポジトリ外とし、`scripts/fetch-assets.mjs` で必ず再取得できる |

## 1. 起動(ビルド)手順

```bash
# 前提: Node.js 18+ (22 推奨) と npm
npm install          # 依存ライブラリ
npm run fetch-assets # 高品質アセット取得(約250MB / GitHub へ sparse clone)
npm run dev          # → http://localhost:5173 を開く
```

ブラウザ(Chrome / Edge / Firefox / Safari 16+)で開き、「はじめる」をクリック。
ポインターロックが有効になります。

```bash
npm run build        # 本番ビルド → dist/ (型検査込み)
npm run preview      # ビルド結果の確認用
npm run typecheck    # TypeScript の型検査のみ
npx tsx scripts/smoke-test.mjs  # ロジックの自動テスト(34件)
```

`?benchmark=1` を付けると全フェーズを自動通しして計測、`?debug=1` でフェーズジャンプが有効になります(後述)。

## 2. 操作方法

| 入力 | 動作 |
|---|---|
| **WASD / 矢印** | 移動 |
| **マウス** | 視点 |
| **Shift** | ダッシュ(歩行の約 2 倍) |
| **E / クリック** | 調べる(PC のぞき込み等) |
| **F** | 懐中電灯(スマホのライト)ON/OFF |
| **C** | ゲーム内コンソール(異世界内) |
| **Esc** | メニュー(感度・音量・グリッチ強度・カメラ揺れ・画質・クレジット) |
| **F3** | パフォーマンス表示(平均 fps / 1% low / 描画統計) |
| マウスカーソル | BSOD の「:(」をホバー → クリック(連打で進行) |

- コンソール: コマンドを入力して **Enter** で実行。**Esc** または空欄で **C** で閉じる。
- BSOD の覗き込み中は **Esc** で立ち去れます。
- 帰還後、PC に触れると最初からやり直せます(状態は完全初期化)。

## 3. 体験の流れ(実装内容)

1. **自室** — モニターの青い光が主光源。PC ファン・時計・遠い車の音。高品質 PBR の家具・小物(FlightHelmet / AntiqueCamera / GlamVelvetSofa / ChairDamask 他)。机の PC に E で覗き込み(頭を傾け、被写界深度が画面に寄る)。
2. **BSOD に食われる** — 「:(」をクリック(7 段階)。文字の乱れ → 画面の剥離 → 部屋の光と空間の歪み → 「:(」が巨大な顔/口へ変質 → 部屋ごと吸い込まれ、**口 → トンネル(喉) → 異世界** をフェードなしの連続カメラで移動。
3. **異世界(複合大マップ)** — ①青い荒野(浮遊破片・エラーモノリス・遠景の中心構造物)→ ②崩壊建築(Sponza を再マテリアル化 + 階段・上階通路・手すりのある立体ホール)→ ③都市の残骸(侵食されたビル群・屋内店舗・破損 UI)→ ④深層(配線とブロックノイズ)→ ⑤中心構造物(門の碑に **WAKE_UP**)。すべてシームレス接続・衝突判定付き。
4. **コンソールと崩壊** — 異世界内で **C**。破損 UI から存在に気づけ、正解コマンドは示されない。`WAKE_UP`(大文字小文字不問)のみ発動: 操作を奪い、**目→頭→体** の視線、ためらい、足取りの乱れ → 足元の亀裂 → 地面が実際に破砕・落下 → 巨大な落下演出(構造物と光が上方へ遠ざかる)。
5. **帰還** — 落下の勢いのまま自室へ着地(天井から入る)。モニターに残るグリッチ・止まった時計・浮遊する小さな破片。再び歩き回れ、PC から最初から遊べる。

## 4. 映像・音・性能

- **映像**: PBR / ACES フィルミック / HDR リニア / 環境 IBL(room.hdr・country.hdr)/ SSAO / ボリュメトリック風フォグ(Exp2 + 遠景 3D)/ Bloom / 被写界深度 / フィルムグレイン / グリッチ(ポスト + **頂点変形 + マテリアル自体の発光ちらつき**)
- **音**: 全合成。部屋(ファン/時計/車)・足音(材質別)・グリッチ・吸い込み・崩壊轟音・落下風・着地・心音。Panner による定位・距離減衰・生成インパルス応答の残響。マスターコンプレッサー + リミッタでクリップ防止。BGM は最小限。
- **安全配慮**: 開始時に注意表示。1 秒 3 回を超える明滅なし。Esc で「グリッチ演出の強度」「カメラ揺れ/ヘッドボブ」を 0 まで下げられる。
- **性能設計**: LOD(遠景インスタンス+フォグ)、視錐台カリング、インスタンシング(破片/文字/モノリス/街灯)、テクスチャ圧縮負荷の低い構成、動的解像度(0.55〜1.0)、品質プリセット 4 段(影・SSAO・DoF・解像度・密度)。

## 5. 性能計測

**この制作環境には GPU もブラウザも存在しないため、実機 fps の計測は行えませんでした**(誠実に明記します)。代わりに:

- `?benchmark=1` を付けて起動すると、**全フェーズを自動で通し**(部屋→BSOD→吸い込み→異世界全エリア→コンソール→崩壊→落下→帰還)、平均 fps / 1% low / 最低 fps を計測して画面(F3)と DevTools コンソール(JSON)に出力します。
- `npx tsx scripts/smoke-test.mjs` によるロジック検証(コンソール入力・衝突・設定・地形)は本環境で実施済み(34 件パス)。
- `npm run build`(型検査+バンドル)と開発サーバーの配信確認は本環境で実施済み。

お手元での計測: `npm run dev` → `http://localhost:5173/?benchmark=1` を開き、自動走査の完了を待つ(F3 で常時表示)。目安として、GTX 1660 級で 1080p・品質「高」60fps を目標にチューニングしてあります(下回る場合は画質プリセットを「中」「低」へ)。

## 8. 既知の制限

- 実機 fps 未計測(上記の通り)。計測値は `?benchmark=1` で確認できます。
- 異世界の各エリアは起動時に一括ロードしています(実行時メモリが軽量なため、描画距離フォグ + 視錐台カリング + インスタンス化 + 遠景 LOD で 60fps を確保する設計)。エリア間の非同期ストリーミング分割は行っていません。
- Sponza は **Cryengine Limited License(非商用・制限付き)**、DamagedHelmet のテクスチャの一部は CC-BY-NC-4.0 です(利用条件は CREDITS.md 参照)。
- WebGL2 非対応環境では起動しません(エラー表示あり)。
- スマートフォン/タブレット操作は対象外(キーボード+マウス必須)。
