# BSOD_EX // 0x000000F4

一人称視点で体験する短編ホラー／グリッチ・インタラクティブ作品（Three.js + TypeScript + Vite）。

## 体験の流れ

1. **夜の自室（02:47 AM）**  
   生活感のある深夜の自室を `WASD` + マウス視点で自由に歩けます。机の上のゲーミングPCのモニターだけが青く光り、静かな不穏さを漂わせています。
2. **本物のBSODと「`:(`」の信号崩壊（SIGNAL DEATH）**  
   PCに近づいて調べ、BSOD左上の大きな `:( ` にカーソルを重ねてクリックを重ねると、画面の**信号そのもの**が死んでいきます。
   - クリック1 **DESYNC** — 顔が色収差のゴーストに分裂し、行が震える
   - クリック2 **MACROLOSS** — マクロブロックが16進の闇に欠け、帯がズレる
   - クリック3 **GLYPH LEAK** — 顔がインクの井戸から逸脱。ゴーストが漂い、データ雨が落ちる
   - クリック4 **FRACUTURE** — 画面にザラついたデータ亀裂。向こう側が光り始める
   - クリック5 **RIFT OPEN** — 亀裂が輝く開口部へ。パネルが奥の光へへこむ
   - クリック6 **INGEST** — 開口部がカメラの道になる。崩壊した信号の川（16進グリフの列・テア・ウィンドウ枠の深み）がGLITCH WORLDの空へ直結
   顔は生物の口ではなく**画面の信号**として描画され（SDF + GPU演出）、部屋全体がモニターの青に侵食されながらモニター内部へ吸い込まれます。
3. **BSODグリッチ世界**  
   歩ける立体地形、巨大サーバー群、空に重なる巨大なウィンドウ枠と逆さの都市、浮遊するCRTモニターや破損UI、マザーボードの断層、静寂と異常波の緩急を備えた3D異世界を探索できます。世界には**とんでもない造形**がぶら下がっています——
   - 聖域の真上：直径50m級の巨大 `:(` データ顔（データオーブ×2 + 48mの括弧アーク、異常時に色収差エコーが点滅）
   - 東の盆地：26mの**フリーズしたカーソル**が空中で停止し、選択枠を点滅させている
   - データ・オーシャン：2本の**データトルネード**が螺旋を上げている
   - 道端：ホログラムの案内端末（発光エミッタ＋スキャンラインの浮遊パネル）
   世界の中心に聳える巨大構造物（Cray-1 演算核）の碑板には、脱出コマンド **`WAKE_UP`** が刻まれています。
4. **ゲーム内コンソール（`C`キー）と世界の崩壊・落下**  
   `C`キーでカーネル回復コンソールを起動できます（**どこからでも開け・実行可能**）。`WAKE_UP` を実行すると崩壊イベントが発生。左右を見回し、足元の亀裂を追い、後ずさりして足場を失い、砕け散る床の破片とともに深淵へ落下する完全一人称の強制カメラ演出が展開されます。
5. **自室への帰還と余韻**  
   落下の勢いのまま深夜の自室のラグへ叩きつけられるように帰還。回転した椅子や机の上に残された青い結晶片、モニターの残留ログなど小さな異変が余韻を残し、そのまま再び探索・再プレイ（`R`キーまたはメニュー）が可能です。

## 操作方法

- `W A S D` / 矢印キー : 移動
- `マウス` : 視点移動 / モニター調査時のカーソル操作
- `左クリック` / `E` : PCモニターを調べる・カーソルを合わせた「`:(`」に触れる
- `右クリック` / `Q` : モニターから離れる（侵食初期のみ）
- ポインターロックが使えない場合は、ドラッグで視点を動かせます。
- 画面の点滅や急な音・カメラ演出があります。
- `C` : ゲーム内カーネルコンソールを開く（異世界内・どこからでも）
- `ESC` : 一時停止・感度／音量設定・やり直しメニュー
