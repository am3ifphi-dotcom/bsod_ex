# BSOD_EX // 0x000000F4

一人称視点で体験する短編ホラー／グリッチ・インタラクティブ作品（Three.js + TypeScript + Vite）。

## 体験の流れ

1. **夜の自室（02:47 AM）**  
   生活感のある深夜の自室を `WASD` + マウス視点で自由に歩けます。机の上のゲーミングPCのモニターだけが青く光り、静かな不穏さを漂わせています。
2. **本物のBSODと「`:(`」の狂気・捕食遷移**  
   PCに近づいて調べ、BSOD左上の大きな `:( ` にカーソルを重ねてクリックを重ねると、微細な表示乱れから次第に文字が剥離し、` :(` 自体が信号欠落や文字の分裂を繰り返し、デジタルの裂け目へと変質していきます。部屋の壁・床・天井までもがモニターの青に侵食されて物理的に引き剥がされ、頭部の抵抗感・ためらいを伴う一人称カメラ演出でモニター内部へ吸い込まれます。
3. **BSODグリッチ世界**  
   歩ける立体地形、崩落する摩天楼、空に反転して吊られた第二の都市、72枚の停止したエラーパネル、マザーボードの断層、静寂と異常波の緩急を備えた3D異世界を探索できます。世界の中心には Cray-1 演算核の聖堂が聳えていますが、**そこへ行かないと何かができない、という制約はありません**。
4. **ゲーム内コンソール（`C`キー）と世界の崩壊・落下**  
   `C`キーでカーネル回復コンソールを起動できます（**どこにいても、いつでも**）。`TRACE` でダンプを走査すると脱出命令 **`WAKE_UP`** が見つかります。`WAKE_UP` を実行すると崩壊イベントが発生。左右を見回し、足元の亀裂を追い、後ずさりして足場を失い、砕け散る床の破片とともに深淵へ落下する完全一人称の強制カメラ演出が展開されます。
5. **自室への帰還と余韻**  
   落下の勢いのまま深夜の自室のラグへ叩きつけられるように帰還。回転した椅子や机の上に残された青い結晶片、モニターの残留ログなど小さな異変が余韻を残し、そのまま再び探索・再プレイ（`R`キーまたはメニュー）が可能です。

## 操作方法

- `W A S D` / 矢印キー : 移動
- `マウス` : 視点移動 / モニター調査時のカーソル操作
- `左クリック` / `E` : PCモニターを調べる・カーソルを合わせた「`:(`」に触れる
- `右クリック` / `Q` : モニターから離れる（侵食初期のみ）
- ポインターロックが使えない場合は、ドラッグで視点を動かせます。
- 画面の点滅や急な音・カメラ演出があります。
- `C` : カーネルコンソールを開く（異世界内・場所を問わずいつでも）
- `ESC` : 一時停止・感度／音量設定・やり直しメニュー

## 意匠メモ

- **BSODパネル**: 実物の Windows 10 ブルースクリーンの組版（本文・QR・停止コード）をそのまま焼き込み、崩壊は
  「その組版が壊れていく過程」として表現しています。走査線の同期外れ、行のスリップ、デコーダのマクロブロック
  脱落、残像、`: ( ` のサッケードと誤植（`)` に化ける）など、実機の壊れ方の順序に沿っています。
- **文字組み**: 日本語は `@fontsource/noto-sans-jp` から**この作品で使う文字だけ**を切り出して同梱
  （`public/fonts/`）。日本語フォントを持たない環境でも、3D空間内の看板やプレートが豆腐にならないようにするためです。
  台詞を追加したら `node scripts/build-jp-font.mjs` を実行してください。
- **演出**: 画面効果は「同時に全部」ではなく、1クリック＝1つの物理的な破損として割り当てています
  （TEAR=水平スリップ、MASH=マクロブロック、ROLL=垂直同期、GHOST=残像、など）。
