# ✝本質✝の教室 — 桐葉高校 北棟 理数科B組

小説『「偏差値60の教室から✝本質✝が漏れ出している件について」』を、
教室3Dモデル `classroom.glb` の中に再構成した体験型ビューアです。

Google Drive「本質images」の**原作テキスト**と**立ち絵26点**、
**教室モデル（classroom.glb）**をもとにしています。
本作は3D空間を舞台にした「紙の切り絵の舞台」で、立ち絵は**原画をそのまま板として貼らず**、
減色・二値化・輪郭線・網点・紙の反りをシェーダで与えて配置しています。

---

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的書き出し
```

ブラウザは WebGL2 が必要です。

## 操作

一人称で教室を歩き、14の「本質」に近づくと場面が始まります。

| 操作 | 内容 |
| --- | --- |
| クリック | ポインタロック（視点操作を開始） |
| ドラッグ | 視点（ロックしていないとき） |
| WASD | 歩く |
| Shift | 走る |
| ← → ↑ ↓ | 視線（キーボードのみでも可） |
| E / Tab | 近くの本質・人物をひらく |
| Space・クリック | 本文を送る（タイプ中なら全文表示） |
| Esc | 閉じる／ポインタロック解除 |
| T | 目次（任意の場面へ跳ぶ） |
| S | 立ち絵スタイル（切り絵 / インク / スペクトル） |
| M | 環境音（すべて手続き生成） |
| H | UI を隠す |

画面の照準（中央の点）が人物に重なると本質度が見られます。
タッチ端末では左スティックで移動、右ドラッグで視点です。

## 歩いて回る

- 教室の床・机・教壇・ロッカー・自販機には当たり判定があり、すり抜けません。
- 各場面の位置には「本質の染み」のマーカーが立っています。**1.25m まで近づくと自動で場面が始まり**ます。
- 場面を読み終えると、まだ見ていない本質が目的（HUD 左上）に切り替わります。
- 14すべてを見終えると、最後に一行だけ表示されます。

## 14の場面

01 序　桐葉高校という二重構造 / 02 両馬二郎の生態系 / 03 火曜三限、味噌の地政学 /
04 本質配信、始動 / 05 金曜五限はいつも死んでいる / 06 砂糖東洋は窓の外を見ない /
07 本質配信 #4 / 08 掲示板の考古学 / 09 三学期・コーンスープの帰還 /
10 ハワイの✝本質✝ / 11 人妻の✝本質✝ / 12 櫻優の理論崩壊 /
13 倉石暁、降臨 / 14 三月の終わり

各場面は「空気（光・時刻・フォグ・ブルーム）」「板書」「窓の外」「小道具」「立ち位置」「カメラ」を持ち、
台詞ごとにカメラが切り替わります。場面が終わると一人称視点に戻り、また歩けます。

## 構成

```
index.html            画面（タイトル／目次／台詞／人物カード）
src/main.js           レンダラ、ポストプロセス、進行
src/world.js          classroom.glb の読み込みと、教室の小道具
src/cutout.js         立ち絵＝紙の切り絵シェーダ（キャスト管理）
src/textures.js       黒板・窓外・自販機・ホログラム・ノート等を Canvas で生成
src/audio.js          環境音（手続き生成のハム・空気・チャイム）
src/ui.js             DOM 側の UI
src/data/scenes.js    14場面の台本（本文・カメラ・配置・環境）
src/data/characters.js 登場人物14人と立ち位置
public/models/        classroom.glb
public/chara/         加工済みの立ち絵（高さ1080px・足元下端）
docs/                 原作テキスト
tools/                アート加工・検査用スクリプト
```

### 立ち絵の加工（`tools/prepare-art.sh`）

原画（`本質images` の `chr_*.png`）を

1. 透明部分をトリムして人物の実寸を得る
2. 高さ 1080px に正規化し、足元を下端・水平中央に固定
3. 128色に減色（＝紙に印刷した切り絵として扱う）

という工程で `public/chara/` に書き出します。
3D 側では「高さ 1.72m × 拡大率」の板にして、足が床に着くように置いています。

```bash
# 原画を置いたディレクトリを指定して実行
bash tools/prepare-art.sh /path/to/chr_png_dir public/chara
```

### 検査（任意・開発用）

```bash
npm i -D jsdom @napi-rs/canvas @shaderfrog/glsl-parser
node tools/smoke.mjs       # GLBパース / 全場面の適用 / 更新ループ / カメラ位置
node tools/glsl-check.mjs  # シェーダの構文
```
