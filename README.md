# bsod_ex — 青い画面の向こう側

一人称・短編ホラー / グリッチ体験。夜の自室でモニターの `:(` をクリックした瞬間から、
**カメラを一度も切らずに** モニターの内側 → BSOD の異世界 → 崩壊 → 自室帰還までを一続きで描きます。

- エンジン: **three.js r186 + Vite 7 + TypeScript**（ブラウザのみで完結）
- 実行時の外部通信: なし（アセットはすべてリポジトリ同梱 / ローカル生成）
- 想定プレイ時間: 15〜25 分（探索の度合いによる）

---

## 0. なぜ three.js か

| 候補 | 判断 |
| --- | --- |
| Unity / Unreal | 高品質な PBR とポストは容易だが、エディタ・ライセンス・数十 GB のビルドチェーンが必要で「`npm install` してすぐ遊べる」形にできない。CI での再現も重い。 |
| Babylon.js | 機能は十分だが、本作が使う EffectComposer 系パス（DOF/GTAO/Bloom/独自最終パス）と glTF 変換パイプラインの実績が three.js の方が厚い。 |
| **three.js + Vite** | **採用**。生の WebGL を直接扱わずに、PBR / ACES / HDR レンダーターゲット / SSAO / Bloom / glTF / インスタンシング / シェーダー注入をフルに使える。`dist/` は 1 MB 弱、`npm run dev` 一発で起動し、ヘッドレス環境でもビルド・自動テストが回る。 |

ポストチェーン（`src/core/postfx.ts`）: `RenderPass → DofPass(自作) → GTAOPass → UnrealBloomPass → Final ShaderPass → OutputPass`。
最終パスで色収差・走査線・ブロックノイズ・フィルムグレイン・ビネット・**1 回だけの青フラッシュ**を合成します。

## 1. 動かす

必要環境: Node.js 20 以上 / WebGL2 が動くデスクトップブラウザ（Chrome・Edge・Firefox・Safari 16+）。

```bash
npm install
npm run dev        # → http://localhost:5173
```

本番ビルド:

```bash
npm run build      # tsc --noEmit && vite build
npm run preview    # → http://localhost:4173
```

`public/assets`（24 MB / glTF + WebP + ogg）を同梱しているので、**取得スクリプトを実行しなくてもそのまま遊べます**。
アセットをゼロから作り直す場合:

```bash
npm run fetch-assets   # Khronos glTF-Sample-Assets / petroulacl fps-asset-kit を sparse clone（要ネットワーク）
npm run build-assets   # 量子化 + 1024px WebP 化 + manifest 生成（sharp / gltf-transform）
```

> ポートを変えたい場合は `npm run dev -- --port 3000`。`vite.config.ts` は `0.0.0.0:5173` 固定・`allowedHosts: true`（プレビュー環境用）。

## 2. 操作

| 入力 | 動作 |
| --- | --- |
| `W A S D` / 矢印 | 移動（1 u = 1 m、歩行 4.3 m/s） |
| `Shift` | ダッシュ（約 1.9 倍 / 8.2 m/s） |
| マウス | 視点（感度 0.2〜3.0 をメニューで即時反映） |
| `E` / 左クリック | 調べる・決定 |
| `F` | ライト（自室: スマホライト / 異世界: フラッシュライト。影は 512px に制限） |
| `C` | 異世界でコンソールを開く（**DevTools ではありません**） |
| `F3` | 性能表示（初期状態は非表示。平均 fps / 1% low / draw call / 解像度スケール） |
| `Esc` | ポーズメニュー（設定・クレジット・再開・はじめから） |
| `F5` | 完全初期化して最初から（ブラウザ再読込の代わり） |

マウスロックが使えない環境（iframe 等）では自動的にドラッグ視点に切り替わります。
`?debug=1` を付けた時だけ、`1`〜`6` のフェーズジャンプと `F9` のデバッグ表示が有効になります。

## 3. 体験の流れ

1. **STILL 01 — 自室（03:07）**
   モニターの青だけが光源の 5.4 × 4.8 × 2.62 m の部屋。PC ファン・壁時計・遠くの車の環境音、机の上の生活感（マグ・ノート・付箋・写真・ミニカー・スニーカー・段ボール）。PC を調べると自然な頭の傾きで寄り、被写界深度が浅くなり、モニターが BSOD で立ち上がる。
2. **`:(` をクリック**
   クリック回数で 5 段階にエスカレート（軽微な文字化け → 走査線の断裂 → 表示の剥離 → 部屋の壁が内側へ撓む → 顔が開口）。10 回で `:(` が巨大な顔／ポータルになり、机の上が吸い込まれ、カメラが口の中へ。
3. **STILL 02 — メモリの外側（異世界）**
   口の内側から**カットなしで**落下し、青い荒野の広場に着地。5 つの領域（青い荒野 / 崩壊した吹き抜け建築 / 侵食された都市（東西）/ 露出した配線の深層 / 中央の巨大構造物）が徒歩で連結。遠景は実ジオメトリ + フォグで LOD 的に見せ、ロード画面も暗転もない。
4. **`WAKE_UP`**
   中央構造物の内部通路を抜けた先、壁一面に `WAKE_UP` が刻まれている。近づくと自動で「読む」演出。壊れた UI の断片が世界の随所にあり、コンソールの存在を**説明的に教えない**。`C` → `help` で命令一覧、未知の入力にはエラーコードで応答する（`WAKE_UP` だけが崩壊を起こす）。
5. **STILL 03 — 崩壊 → STILL 04 — 帰還**
   入力は完全にロックされ、視線が先 → 頭が遅れて追う人間的なカメラで亀裂を追う。地面が割れて破片とともに落下し、構造物と光が上方へ流れる。落下の勢いのまま自室の天井を突き破って着地（カットなし）。直後は椅子の向き・写真・時計の針・ドアの隙間の光などが僅かにずれている。`F5` かメニューの「はじめから」で完全初期化して再プレイ可能。

## 4. 実装メモ

### ワンカット遷移
すべて `src/game/Director.ts` の位相機械（`room → leanin → screen → finale → drop → void → collapse → fall → return → room`）が単一カメラを所有します。

- 寄りは `CameraScript`（位置・注視点・FOV・ロール・フォーカス・揺らぎのキーフレーム補間）で記述。
- 画面 → 口 → 異世界は **1 回の減衰する青フラッシュ**（`uFlash`）で継ぎ目を隠し、その瞬間にカメラを口の内側のトンネルへ移す。点滅ではなく単発。
- 崩壊は「目 → 頭 → 体」の順に視線が動くようキーフレームを組み、`shakeCamera` と呼吸・心拍を重ねる。地面が割れた地点から実際に落下し、`Tunnel` のテクスチャスクロールで速度感を出す。
- 落下 → 自室の天井へは、**落下シャフトの内側（画面がほぼ埋まる瞬間）にシーンを差し替える**ことでカットを作らない。

### 衝突
`src/core/collision.ts` の AABB ベース（platform / blocker / ramp / terrain）。
- 段差の自動ステップ（0.55 m まで）、サブステップ移動でダッシュ時も壁抜けなし。
- 建築物の内部は地形コリジョンを無効化し、床スラブと階段が歩行面を担当（地下への吹き抜けを地形が埋めないように）。
- マップ外縁は不可視の境界で塞ぎ、落下は崩壊演出中（`allowFalling`）のみ。それ以外は 8 m 以上落ちると最後の安全地点へ戻す。
- 検証は `tools/smoke.ts` が実際にプレイヤーを歩かせて確認（後述）。

### 世界（`src/game/World.ts` / レイアウトは `WORLD` 定数が唯一の真実）
- 到着広場 + 巨大な `:(` の門（落下してくる口）、浮遊島、コンソールのヒントになるキオスク。
- 3 層の吹き抜け建築（1F リング状床 + 中央の吹き抜け、y=4.2 の U 字バルコニー、y=8.4 のメザニン、2 連の階段、手すり、光の柱、壊れた UI パネル、BSOD 化した glTF 家具 7 点）。
- 東西の都市（インスタンス化した窓・エラーオーバーレイ・2 本の橋）。
- 深層 y=−12（二段の折り返し階段、配線チューブ、ブロックノイズ、隠しデスク）。
- 中央構造物（4 段の土台、15 枚のスラブと発光シーム、5 つの周回リング、ビーコン、`WAKE_UP` の間）。
- 破片 480 / 文字の雨 600 をインスタンス描画。距離フォグ + 実ジオメトリの遠景。

### グリッチは「絵」だけでなく実体にも
`src/core/materials.ts` が `onBeforeCompile` で全ワールドマテリアルに注入:
- 頂点: 低周波のうねり、水平ブロック単位のスライスずれ、プレイヤー近傍の頂点飛散。
- 断片: 発光への走査線・ノイズバンド。
- ライト: 画面光の明滅（2 Hz 以下）、崩壊時の亀裂光源。
- ポスト: 色収差・ブロック変位・ワープ・フィルムグレイン。

### コンソール（`src/game/Console.ts`）
`help / status / ls / cat <file> / ping / who / clear / exit / sudo / shutdown / wake_up ...`
未知の入力は `ERROR 0x????` + 意味不明な警告で返す。`WAKE_UP`（大小文字・空白・アンダースコアの揺れを正規化）だけが崩壊を起こし、二重発火しない。
開いている間はゲーム入力を完全に止め（`freeze`）、閉じるときに pointer lock / キー状態 / IME を確実に復帰させます。

### 音（`src/core/audio.ts`）
- 環境音・グリッチ・崩壊・落下・心拍・帰還和音は **すべて Web Audio のリアルタイム合成**（ライセンスフリー）。残響 IR も実行時生成。
- 足音のみ CC0 サンプル（Fantozzi's Footsteps）。合成フォールバックあり。
- 空間音響: HRTF パンナー + 距離減衰。異世界の各構造物に固有周波数のハミング音源を配置。
- マスターにコンプレッサ（threshold −14 dB / ratio 5）を挿し、大音量の衝突でもクリップしないよう管理。

### 設定と安全
- 開始時の注意表示、`グリッチ演出の強度` / `カメラ揺れ` / 音量 / 感度（0.2〜3.0、即時反映）/ 画質 4 段階 / 動的解像度。
- 点滅は 1 秒 3 回以下（画面の明滅は 2.2 Hz、フラッシュは単発）。
- 90 秒以上操作がない場合も含め、ポーズ中はゲーム入力を完全停止。

## 6. パフォーマンス

### 目標
1080p / RTX 3050・GTX 1660・M1 クラスで **60 fps**（全フェーズ、1% low 50 fps 以上）。

### 実装している最適化
- インスタンシング（瓦礫・窓・文字の雨・地面の刻印・キーキャップ）
- 影を落とすライトを 3 灯までに制限し、マップサイズを 512〜1024 に固定
- 動的解像度（0.55〜1.0、`setScale` で描画バッファのみ変更）
- 画質プリセットで GTAO / Bloom / DOF / 影 / グレインを段階的に無効化
- ポストは HalfFloat の単一 RT + 深度テクスチャを共有
- 描画は 1 パスのみ（シーン切替式。部屋と異世界を同時に描かない）
- 遠景は実ジオメトリ + `FogExp2`（ビルボードの LOD 差し替えなし）

### 計測値について（重要）
**このリポジトリを整備した環境は GPU のないヘッドレスコンテナで、ブラウザも存在しないため、実 fps と 1% low を計測できませんでした。**
したがって本 README に「実測 60 fps / 1% low 52 fps」のような数値を書くことはできません（書けばそれは捏造になります）。

計測手順（対象ハードで 1 分で終わります）:

1. `npm run build && npm run preview`
2. `?debug=1` を付けて起動（任意。フェーズジャンプ用）
3. ゲーム内で `F3` → 右上に **平均 fps / 1% low / frame ms / draw call / 三角形数 / 解像度スケール** が出ます
4. `1`〜`6` で各フェーズに飛び、それぞれ 10 秒以上滞在した値を記録

フェーズごとの目安（設計上の draw call 数）: 自室 60〜90、異世界の到着 90〜140、建築 150〜200、都市 180〜240、崩壊 250 前後。
これを超える場合は `画質: 中` か動的解像度で調整してください。

## 7. テスト / 検証

```bash
npm test
```

3 層のテストが走ります（すべてヘッドレス・GPU 不要）。

1. **ロジック単体（`tests/logic.test.ts` / 16 件）**
   コリジョンの段差・壁押し出し・埋まり復帰、プレイヤーの前進/壁/段差/落下/ダッシュ貫通/ヘッドボブ、`CameraScript` の補間とクランプ、コンソール（空 Enter・未知コマンド・`WAKE_UP` の表記揺れと二重発火・大文字小文字）。
2. **ワールド衝突スモーク（`tools/smoke.ts`）**
   実際の `Room` / `World` を構築し、プレイヤーを歩かせて検証:
   - 自室: 6 方向に歩いても外へ出ない、机へ侵入しない
   - 異世界: 到着地点 → 建物外周 → 北の通路 → 中心構造物の内部通路 → `WAKE_UP` の間まで**実際に徒歩で到達**（y = 0.40 で停止）
   - 2F バルコニー → 橋 → 都市東（y = 4.20 を維持）
   - 1F 吹き抜け → 二段階段 → 深層 y = −12
   - 階段の高さが 2F（4.2 m）まで連続していること
   - 端まで走ってもマップ外へ出ない・落下しない
3. **ディレクター通し（`tools/director-smoke.ts`）**
   UI / ポスト / 音をスタブして**位相機械を最後まで実行**:
   `room → leanin → screen →（12 クリック）→ finale → drop → void`（着地点が到着広場であること）→ `collapse → fall → return → room`、異常化フラグ、`restart()` による完全リセット、6 つのデバッグジャンプ。

### この環境で検証できなかったこと（正直な申告）
- **実 fps / 1% low**（GPU・ブラウザなし）
- **見た目**（照明・ポストの強さ・UI の重なり・フォントの描画）— 実ブラウザでの目視が必要
- **音の実際の聞こえ方とラウドネス**（AudioContext はブラウザでのみ動作）
- **マウスロック / IME / タッチパッド等のブラウザ固有挙動**
- **モバイル・Safari での動作**
- **プレイ時間 15〜25 分**は設計上の見積り（実測ではありません）

## 10. 既知の制限

- ポインタロック非対応の iframe ではドラッグ視点になります（タッチ操作は未対応）。
- 音はブラウザの自動再生制限のため、スタートボタンのクリック後に初期化されます。
- 影はスポット/ポイント計 3 灯まで。それ以上の光源は影なしのポイントライトです。
- 異世界の遠景は「実ジオメトリ + フォグ」で、ビルボード LOD への差し替えは行っていません（見た目の破綻を避けるため）。
- 動的解像度は描画バッファのみを下げるため、UI は常に等倍です。
- 実 fps の計測は未実施（第 6 章）。
