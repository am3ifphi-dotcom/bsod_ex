# SKETCHFAB ARCHIPELAGO · 3D探検世界

Sketchfab の公開フィード（新着モデル）を「浮島の群島」として歩き回れる 3D ワールドです。
**全部は読み込まない**設計にしてあります。

- 一覧 API は起動時に **1 回だけ**（24 件）
- サムネイルは **近づいた島の分だけ**、同時 3 本まで
- 3D モデルは **「3Dビューアで開く」を押した 1 体だけ**（閉じると iframe ごと破棄）
- 画面外の島・遠い島は描画も読み込みもしない

## 起動

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ に静的出力
npm run preview
```

## 操作

| 操作 | キー |
| --- | --- |
| 前後左右 | `W` `A` `S` `D` / 矢印キー |
| 加速 | `Shift` |
| 上昇 / 下降 | `Space` / `C`（`Q` も下降） |
| 視点 | マウスドラッグ（ホイールで画角） |
| 島を開く | 島をクリック、または `E` |
| 次の未発見の島 | カード内のリンク |
| ヘルプ | `H` |
| 環境音 | `M` |
| 開始位置へ戻る | `R` |
| 閉じる | `Esc` |

モバイルは画面ドラッグで視点、左下のスティックで移動、島をタップで自動航行。

## 軽さのための仕組み

| 仕組み | 実装 |
| --- | --- |
| 近傍ストリーミング | `src/thumbnails.js` — 距離 34 以内のみ、同時 3 本、画面外の要求は破棄 |
| 単一ビューア | `src/viewer.js` — iframe は開いたときだけ生成、閉じると即破棄 |
| サムネイルは HTML で重畳 | WebGL テクスチャにしないので CORS の影響を受けず、GPU メモリも使わない |
| 動的解像度 | `adaptQuality()` — fps<42 で解像度を、fps<34 でブルームを自動オフ |
| 後乗せブルーム | `three/addons` を動的 import（初期バンドルに含めない） |
| ジオメトリ共有 | 岩・輪・欠片はインスタンスを使い回し、破棄時はマテリアルのみ解放 |

fps チップをクリックすると、サムネイル読込数・転送中・ビューア数・三角形数・ドローコールが確認できます。

## データ

- 取得: `https://api.sketchfab.com/v3/models?sort_by=-publishedAt&count=24`（公開・認証不要）
- ブラウザから直接取得できない環境では Vite プロキシ `/api/sketchfab` を経由
- どちらも失敗した場合は、キュレーション済みのサンプル世界で起動（UI に `SAMPLE WORLD` と表示）
- 3D 表示は Sketchfab 公式埋め込み。モデルのライセンスは各作者に帰属します

## テーマ

`すべて / 自然 / 建物 / 乗り物 / アート / 科学` で、取得済みモデルから島を再構成します。
テーマを変えると空・海・光のパレットも補間アニメーションで切り替わります。

## 構成

```
index.html            画面構造（HUD・カード・ビューア・起動画面）
src/main.js           起動・状態・HUD・メインループ
src/world.js          Three.js の世界（島・空・海・星・塵・テーマ・ブルーム）
src/controls.js       WASD 探検コントロール + 自動航行
src/sketchfab.js      フィード取得・正規化・テーマ分類・埋め込み URL
src/thumbnails.js     近傍サムネイルストリーマ
src/viewer.js         Sketchfab 埋め込みのライフサイクル管理
src/minimap.js        レーダー描画
src/audio.js          WebAudio の環境音（外部音源なし）
src/style.css         UI スタイル
```
