# BSOD_EX // 0x000000F4

一人称視点で体験する短編ホラー／グリッチ・インタラクティブ作品（Three.js + TypeScript + Vite）。

## 体験の流れ

1. **夜の自室（02:47 AM）**  
   生活感のある深夜の自室を `WASD` + マウス視点で自由に歩けます。机の上のゲーミングPCのモニターだけが青く光り、静かな不穏さを漂わせています。
2. **本物のBSODと「`:(`」の狂気・捕食遷移**  
   PCに近づいて調べ、BSOD左上の大きな `:( ` にカーソルを重ねてクリックを重ねると、微細な表示乱れから次第に文字が剥離し、` :(` 自体が激しく痙攣・変質して3Dの裂け目（深淵の喉）へと開いていきます。部屋の壁・床・天井までもがモニターの青に侵食されて物理的に引き剥がされ、頭部の抵抗感・ためらいを伴う一人称カメラ演出でモニター内部へ吸い込まれます。
3. **BSODグリッチ世界**  
   歩ける立体地形、巨大サーバー群、浮遊するCRTモニターや破損UI、マザーボードの断層、静寂と異常波の緩急を備えた3D異世界を探索できます。世界の中心に聳える巨大構造物（Cray-1 演算核）へ辿り着くことで、脱出コマンド **`WAKE_UP`** を発見できます。
4. **ゲーム内コンソール（`C`キー）と世界の崩壊・落下**  
   `C`キーでカーネル回復コンソールを起動し、`WAKE_UP` を実行すると崩壊イベントが発生。左右を見回し、足元の亀裂を追い、後ずさりして足場を失い、砕け散る床の破片とともに深淵へ落下する完全一人称の強制カメラ演出が展開されます。
5. **自室への帰還と余韻**  
   落下の勢いのまま深夜の自室のラグへ叩きつけられるように帰還。回転した椅子や机の上に残された青い結晶片、モニターの残留ログなど小さな異変が余韻を残し、そのまま再び探索・再プレイ（`R`キーまたはメニュー）が可能です。

## 操作方法

- `W A S D` / 矢印キー : 移動
- `Space` : ジャンプ（微ジャンプ用の着地スプリング＆衝撃音つき）
- `マウス` : 視点移動 / モニター調査時のカーソル操作
- `左クリック` / `E` : PCモニターを調べる・「`:(`」をクリック
- `右クリック` / `Q` : モニターから離れる（侵食初期のみ）
- `C` : ゲーム内カーネルコンソールを開く（異世界内）
- `ESC` : 一時停止・感度／音量設定・やり直しメニュー

## ビジュアル／操作の調整メモ

- 高DPI対応: 描画バッファを最大1.5×デバイスピクセルで再構成し、PostFX側でCAS系シャープ＋FXAAライトを適用。自室の解像感を優先。
- 周辺視野レンズ: 画面中心はクリアなまま、視野の外周だけがブロックノイズと走査線でわずかに解像度が落ちるフィルターを常時薄く適用（異世界ではやや強め）。
- 視点依存: 天球の巨大な「眼」は固定のワールド方向にあり、見つめるほど画面にグレア／アナモルフィック・フレアが差し込む。
- 空の喉の出口: 歯を全廃し、滑らかなベルのすぼまり＋有機的な唇のカラー＋開口部のもやへと継ぎ目なく移行。着地後も見上げれば無歯の顎が残る。
- 雨: ガラス面の水滴は重力で流れるヘッド＋軌跡＋鏡面ハイライト、窓の外には風に流される3D雨条を追加。
- 歯: 飲み込まれる際の歯を寄生獣寄りの太い歯冠（40本＋咽頭96本）に変更。
